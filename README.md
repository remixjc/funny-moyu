# 节前摸鱼研究所

> 放假前综合征治愈站：光明正大摸鱼五分钟，元气满满回来干活。
> 纯静态单页，零依赖，push 到 GitHub Pages 即可上线。

## 功能

- 放假倒计时（三态：放假前 / 假期中 / 假期后，目标 2026-10-01 00:00 起）
- 摸鱼指数测试（10 题 → 6 段位，段位本地存档）
- 摸鱼理由生成器（50+ 条、5 类，一键复制）
- 老板键（快捷键 `~` 或悬浮按钮，切入假工作界面，标题/favicon 同步切换）
- 今日不宜工作签文（按日期固定，当天不换签）
- 节前综合征诊断报告（Canvas 生成 PNG，可下载分享）
- 摸鱼打卡（累计 / 连续天数）
- 深色模式（跟随系统 + 手动切换）

## 快速开始

本地直接双击 `index.html` 即可使用，无需服务器。

## 部署到 GitHub Pages

1. 将本项目推送到 GitHub 仓库（如 `mo-yu-station`）；
2. 仓库 **Settings → Pages → Source: Deploy from a branch**；
3. Branch 选 `main`，目录 `/ (root)`，Save；
4. 等待 1-2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

改代码 → `git push` → 自动生效。

## 自定义假期

修改 `index.html` 内 `MY_CONFIG` 的 `HOLIDAY_START` / `HOLIDAY_END` 两个常量即可切换任意假期，无需改其他代码。
